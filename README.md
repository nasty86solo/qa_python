# qa_python
Для приложения BooksCollector были написаны следующие тесты:
1. Добавление новой книги с названием до 40 символов, 40 символов, 41 символ и пустое название
2. Повторное добавление существующей книги
3. Правильная установка жанра
4. Получение книг определённого жанра
5. Вывод жанра книги по её названию
6. Получение детских книг допустимого жанра
7. Добавление книг в избранное
8. Удаление избранны книг
9. Получение списка избранных книг
